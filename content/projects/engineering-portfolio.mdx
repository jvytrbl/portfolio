## Problem

A portfolio that proves engineering skill, not just lists it, while costing nothing to run.

## Architecture

Content lives in Git as MDX and YAML, validated by Zod schemas at build time and prerendered to
static HTML. Dynamic features (contact form, view counters) use free-tier Supabase.

## Outcomes

- Every page is static and served from the edge.
- Content mistakes fail the build instead of breaking production.
