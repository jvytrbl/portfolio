## Problem

A portfolio that proves engineering skill rather than listing it, while costing nothing to run.

## Solution

Content lives in Git as MDX and YAML, validated by Zod schemas at build time and prerendered to
static pages. The contact form and view counters run on free-tier Supabase, Resend, and Cloudflare
Turnstile, with every integration optional so the site always builds.

## Outcome

Static pages served from the edge, content mistakes that fail the build instead of production,
and unit, integration, and end-to-end tests on every push.
