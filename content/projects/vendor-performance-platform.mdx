## Problem

Procurement teams scored vendors by hand in spreadsheets. Data came from several ERP exports,
definitions drifted between teams, and every quarterly review took days of manual reconciliation.

## Architecture

The platform pulls ERP data on a schedule, normalises it into a single scoring model, and serves
dashboards and exportable reports behind company single sign-on.

```txt
ERP exports ──► ingestion job ──► SQL Server (normalised) ──► scoring service
                                                         └──► Next.js dashboard ──► PDF / Excel export
```

### Scoring model

Scores are computed in a pure function so they can be unit tested and mutation tested in isolation:

```ts
type Metrics = { onTimeRate: number; defectRate: number; responseHours: number };

export function scoreVendor({ onTimeRate, defectRate, responseHours }: Metrics): number {
  const delivery = onTimeRate * 50;
  const quality = (1 - defectRate) * 35;
  const service = Math.max(0, 15 - responseHours / 4);
  return Math.round(delivery + quality + service);
}
```

## Outcomes

- Quarterly reviews went from days of spreadsheet work to a one-click export.
- One shared definition of "vendor performance" across departments.
- Regression-safe scoring thanks to unit and mutation tests.

## What I'd do differently

Start with event-driven ingestion instead of batch exports, to give near-real-time scores.
